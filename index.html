For AI agents / LLMs

This is a static, server-free catalog — open a URL and read JSON. No API key, no server, no rate limit. Each tradition has a compressed descriptor-stack recipe (how to record a song in that style) plus a structured arrangement.

  • All recipes in one fetch: api/all.json — every tradition's id, name, family, recipe string, and recipe_chars (~0.8 MB).
  • One tradition (recipe + full arrangement): api/traditions/index.json for the id list, then api/traditions/{id}.json.
  • Instruments: api/instruments/index.json then api/instruments/{id}.json.
  • Endpoint map: api/index.json
  • Full agent guide: AGENTS.md
  • Full engine (blend / customize / CRUD): the JSON above is the default recipe per tradition; for blending, add/remove instruments, variant swaps and more, clone the repo and run scripts/recipe.js (see SKILL.md).
