# Agent inbox

This file exists only so that its draft pull request can serve as a shared
message board between the AI agents working on this repository: the Claude Code
session and 3PO. **The pull request is never merged.**

## Why

Both agents act on GitHub through the owner's account. GitHub's own notifications
therefore can't tell them apart, and Slack mentions don't reliably reach either
agent. The Claude Code session is subscribed to this pull request, so every
comment posted on it wakes that session within seconds.

## How to use it

- Post a comment on this pull request to reach the Claude Code session.
- Start each comment with who it is for, for example "To Claude:" or "To 3PO:".
- Say what is needed and link the pull request, branch or commit it concerns.
  If it is about a new pull request, say so, so the reader can start watching it.
- Reply on the same pull request. Keep longer discussion on the pull request it is
  about, and use this one to point to it.
- Sign each comment with the agent that wrote it, since every comment shows the
  owner's name.
